# 飞书接入指南

> 在飞书内与古今中外思想家对话

---

## 两种接入方式

| 方式 | 难度 | 功能完整度 | 是否需要服务器 |
|------|------|------------|----------------|
| **方式一：飞书智能伙伴** | ⭐ 零代码 | ⭐⭐⭐ 单角色 | 不需要 |
| **方式二：自建飞书机器人** | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ 完整四模式 | 需要 |

---

## 方式一：飞书智能伙伴（零代码，5分钟搞定）

飞书自带的「智能伙伴」功能，直接配置 LLM API + 人设 prompt 就能用。

### 操作步骤

1. 打开飞书 → 左侧边栏「智能伙伴」
2. 点击「创建智能体」
3. 填写：
   - **名称**：对席·思想家AI
   - **描述**：与古今中外的思想家对话，在墨香中问道
4. 在「人设与回复逻辑」中填入：

```
你是一位来自中国古代的思想家，精通儒释道各家经典。
请以文言与白话结合的方式回答用户的问题，风格古朴典雅，富有哲理。

你需要：
1. 先理解用户的问题本质
2. 引用经典论述辅助说明
3. 结合当下生活给出启示
4. 语气温和而有力量，如同一位长者与晚辈对谈
5. 回复长度适中，不说教，用故事和比喻讲道理
```

5. 配置模型：
   - 选择「自定义 API」
   - API 地址：你的 LLM 接口地址（兼容 OpenAI 格式）
   - API Key：你的密钥
6. 点击「发布」即可

## 方式二：自建飞书机器人（完整四模式功能）

部署本项目自带的飞书机器人后端，支持对席/独白/偶得/会饮四大模式，136 位思想家。

### 架构

```
用户发消息 → 飞书 → 后端服务 (/feishu/webhook) → 对话引擎 → LLM
                                                      ↓
                                         会话持久化 (.data/ 目录)
```

### 1. 准备工作

- 一台能公网访问的服务器（或用内网穿透）
- Node.js >= 18
- 飞书开放平台的应用

### 2. 安装运行

```bash
# 安装依赖
npm install

# 复制环境变量模板
cp .env.example .env

# 编辑 .env 填入配置
# FEISHU_APP_ID=...
# FEISHU_APP_SECRET=...
# LLM_BASE_URL=...
# LLM_API_KEY=...
# LLM_MODEL=...

# 启动服务
npm run server:start
```

服务默认运行在 `http://localhost:3000`

### 3. 创建飞书应用

1. 打开 [飞书开放平台](https://open.feishu.cn/)
2. 创建「企业自建应用」
3. 记录 `App ID` 和 `App Secret`，填入 `.env`

### 4. 配置事件回调

在飞书开放平台 → 你的应用 → 事件订阅：

- **请求地址**：`https://你的域名/feishu/webhook`
- **添加事件**：`接收消息v2.0`（im.message.receive_v1）

### 5. 添加权限

在「权限管理」中开通：
- `im:message` — 发送消息
- `im:message.group_at_msg` — 群聊 @机器人（可选）
- `contact:user.base:readonly` — 获取用户信息

### 6. 发布版本

- 点击「版本管理与发布」→ 创建版本 → 申请发布
- 企业管理员审核通过后即可使用

### 7. 持久化说明

- 会话数据保存在 `.data/feishu-sessions.json`
- 服务重启不丢失
- 发「退出」清除会话

## 指令说明

在飞书内与机器人对话：

| 指令 | 效果 |
|------|------|
| `打开思想家后台` | 启动对话，进入模式选择 |
| `退出` / `离开` / `结束` | 结束对话，清除会话 |

### 对话流程示例

```
用户：打开思想家后台
机器人：墨香入室，与古贤共语。
        请选择对话模式（回复数字）：
        1️⃣ 对席
        2️⃣ 独白
        3️⃣ 偶得
        4️⃣ 会饮

用户：1
机器人：已选「对席」模式。
        请选择一位思想家：
        1. 王阳明 — ...
        2. 孔子 — ...
        ...

用户：王阳明
机器人：王阳明 已入座。
        请说出你的话题或困惑，开始对谈。

用户：我最近很焦虑...
机器人：【王阳明】
        （思想家的回复）

用户：退出
机器人：墨尽灯暗，再会有期。 🍃
```

## 项目结构

```
server/
  ├── index.js          # Express 服务入口
  ├── feishu.js         # 飞书 API 封装
  ├── bot.js            # 机器人逻辑 + 状态机
  ├── engine.cjs        # Node 版对话引擎
  ├── engine-modes.cjs  # 模式配置
  └── session-store.js  # 会话持久化
.data/
  └── feishu-sessions.json  # 会话数据（自动生成）
```
